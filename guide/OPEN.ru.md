## Что нужно владельцу или исследователю

Это пробелы и несоответствия, найденные при реструктуризации. Исходные файлы **не** менялись, чтобы их исправить.

1. **Текста протокола здесь нет.** Протокол v8.3 назван завершённым, но его текста в репозитории нет (есть только протокол exp29). Диапазоны целей и дизайн на <!--n:seeds_total-->15,600<!--/n--> семян не прослеживаются до него. (`README.md:58`)
2. **Заголовок статуса отстаёт от работы.** Прежний README датирован июлем 2026 и пишет «Протокол готов, подготовка оборудования», тогда как exp29, микроскопические отчёты и панель по редису уже в репозитории; аппаратура эмиттера нигде не описана. (`README.md:362`)
3. **«Количественных результатов нет» против отчётов с числами.** README говорит, что их нет, тогда как три отчёта дают числа. Это пилотные показатели, а не результаты RCT, но README отчётов не упоминает; история git показывает, что аналитику убрали из README намеренно 2026-06-15 ради «только внешнего вида». (`README.md:60`)
4. **Число кадров микроскопии.** Отчёт 2026-07-02 говорит о <!--n:micro_report_frames-->8<!--/n--> кадрах (3 контроль, 5 обработка), но в `blind_key.tsv` <!--n:micro_key_rows-->9<!--/n--> строк (<!--n:micro_key_control-->3<!--/n--> контроль, <!--n:micro_key_treated-->6<!--/n--> обработка), а заметки входящей партии говорят, что отчёт использовал 9. (`reports/2026-07-02_microscopy-cell-structure/blind_key.tsv`)
5. **Кадра редиса нет в манифесте фото.** Кадр называется `microgreens_2026-05-11.jpg` и лежит в папке отчёта; манифест из <!--n:photos-->23<!--/n--> фото охватывает <!--n:photo_first-->2026-05-02<!--/n--> — <!--n:photo_last-->2026-06-10<!--/n--> и записи про редис не содержит. (`reports/2026-06-16_llm-blind-photo/charts/microgreens_2026-05-11.jpg`)
6. **Exp29 и «эксперимент 17».** Отчёт о закладке exp29 упоминает отдельный посев, смешанный в тот же набор фото, без протокола в репозитории; макрофото несут три системы кодирования групп. (`reports/2026-06-29_exp29-setup-observation/report_ru.md:25`)
7. **Какой кристалл?** Ветвь с кристаллом (G7) не говорит, какой кристалл используется и является ли он кристаллом DAAT соседнего исследования. (`README.md:121`)
8. **Статус патента.** Прежний README пишет «экспертиза по существу»; независимого подтверждения в репозитории нет, и заявителей он не называет (см. [ИС, команда и экосистема](ECOSYSTEM.ru.md#связь-с-патентом)). (`README.md:241`)
9. **Подгружаемые диаграммы.** Прежняя главная страница грузила три диаграммы по старому публичному имени репозитория; витрина ссылается на закоммиченные файлы. (`README.md:129`)
10. **Какие папки на каком уровне безопасности.** 4-уровневая классификация названа, но ни одной папке уровень не назначен. (`README.md:303`)
11. **План против реального расписания.** Задачи по фазам #4-#8 открыты со сроками Q2-Q3 2026, а схема плана ожидает старта основного эксперимента в июне 2026; основного эксперимента в репозитории нет. (`README.md:100`)
12. **Перципиентный слой.** Здесь не записано, согласились ли участники на упоминание в этом (публичном) репозитории; файлы на этих страницах не описываются. (`reports/percipient_reports/`)
13. **Задачи GitHub.** Таблица задач скопирована из прежнего README; сами задачи не перечитывались.

## Не проверено витриной

Результат на 52 кадрах пересчитан только из закоммиченного `per_frame_metrics.json` (медианы); ни один аналитический скрипт не запускался. Изображения, кроме трёх диаграмм плана и одного фото рукописного протокола, по одному не просматривались. 20-МБ видео первого дня в .gitignore и отсутствует. Внешние инструменты из отчётов (модель зрения, DINOv2, Cellpose, LeafNet) заново не запускались.
